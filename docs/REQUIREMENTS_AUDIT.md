## Исправлено во время аудита

- Кодировка текста Historical Replay и отображение года выбранной даты.
- Историческая дата в общей шапке, ORIGIN на архивном графике и подпись TODAY на обычном.
- Выбор обеих турбин в объяснении; данные объяснений вынесены из UI в mock/service слой.
- Кнопка Settings на узком экране.
- Реальное переключение 24h/48h на Overview.
- Строка последнего действия агента и следующего обновления над KPI.
- Проверка недопустимых исторических дат и состояния leakage check.
- Соответствие утреннего диапазона неопределённости времени UTC в разных сценариях.
- Разделение unit- и browser-тестов; разбиение production JavaScript по страницам и библиотекам.
- Форматирование исходников и документация запуска/интеграции.

## Проверки

- `npm run build`: TypeScript и production-сборка.
- `npm test`: 11 тестов контрактов и согласованности данных.
- Browser suite: основной demo flow, drawer, CSV, Copilot, recovery, replay, notifications, scenarios, mobile navigation.
- Все шесть страниц проверены на ширине 390 px.
- Overview дополнительно проверен на 360×800, 768×1024, 1024×768, 1440×900 и 1920×1080; горизонтального переполнения не найдено.
- Браузер проверки: Microsoft Edge / Chromium, headless. Проверка других браузерных движков не выполнялась.

## Границы demo

Реальные weather API, ML-модель, архив прогнозов, LLM и автономный backend пока не подключены — согласно исходному ТЗ используются mocks. Проверка отсутствия будущих данных относится к демонстрационным временным меткам, а не к независимому аудиту production-архива. Демо-часовая зона — UTC, операционная дата фиксирована на 23 сентября 2026.
