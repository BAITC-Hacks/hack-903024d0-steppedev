# Локальные данные и артефакты

Содержимое рабочих папок игнорируется Git. В репозитории сохраняются эта инструкция и `.gitkeep`, чтобы структура была видна после клонирования.

```text
storage/
  data/raw/        исходные CSV турбин
  data/processed/  подготовленные датасеты
  models/          веса моделей, metadata, validation predictions
  weather/         погодные снимки по времени получения
  forecasts/       экспортированные прогнозы
  reports/         результаты анализа и отчёты
```

Из старой папки `task/` перенесены все существующие CSV, модели и погодные ответы. При переносе содержимое проверено по SHA-256.

На новом компьютере для запуска подготовки данных необходимо отдельно получить `turbine_1.csv` и `turbine_2.csv` и поместить их в `data/raw/`. Для использования готовой модели нужно отдельно получить артефакты или выполнить обучение.

Большое хранилище можно вынести за пределы проекта через переменную `WINDOPS_STORAGE_DIR`; подробности в `backend/README.md`.

Ранее закоммиченные данные остаются в истории Git. Реорганизация не переписывает историю; после коммита переноса актуальное дерево будет хранить здесь только инструкции и маркеры папок.
